# 工具箱 · Toolbox

面向开发者的跨端（PC + 移动端）工具箱，按 Claude Design 交付的高保真原型（`design/project/Toolbox.dc.html`，1a 经典侧栏方向）实现。

## 产品原则

1. **操作路径最短**：用户想做一件事时，从打开页面到拿到结果，操作步骤要尽可能少。
2. **不悄悄改动数据**：格式化、转换、对比、编码都不能悄悄改变数据；不支持的情况要说明原因。

两条冲突时以第 2 条为准。比如可以按内容自动判断用户的意图，但判断结果必须显示出来，并且一次点击就能改回。

新增或修改功能时，先数一数完成最常见的那件事要几步，看能不能再少一步，再对照下面的约定检查。

### 1. 操作路径最短：具体约定

**打开就能输入。** 桌面端切换到工具后，光标已经在主输入框里，不用先点一下输入框。如果用户已经点进了别的输入框，光标不会被抢走。

**结果随输入出现。** 没有"转换""计算""生成"按钮。

**点了就有反应。** 需要时间的操作会立即显示正在进行，不让用户以为没点上，比如复制图片、计算大文件的哈希（带进度）、处理大段输入。

**点结果就复制，而且只有这一种方式。** 结果本身就是复制按钮，旁边不再放"复制"按钮或"复制"字样，避免同一件事出现两个入口。鼠标移上去整块高亮，停留时提示"点击复制"，复制后显示"已复制"。
- **单个值**：点这一行的任何位置都复制。包括时间戳页的全部结果、顶部"现在"一栏、哈希值、差异清单里的路径、识别出的二维码内容、URL 的各部分和每个查询参数、JWT 的时间、各进制的结果、命名转换的每种写法、字数统计的每项、正则的每处匹配和分组、颜色的每种写法、Cron 的描述和每次执行时间。
- **二维码图片**：点二维码复制图片。
- **大段结果文本**（Base64、URL / Unicode / HTML / Hex 编解码、转义、YAML / XML / SQL 格式化的结果，格式化的"文本"视图，文本对比结果，生成的 UUID 列表）：点一下复制全部；拖动可以只选中其中一部分，再用 ⌘C / Ctrl C 复制选中的部分。Base64 的十六进制视图点一下复制的是不带空格和偏移的十六进制字符串。

一个例外：格式化默认的"结构"视图里，每一行有"路径"和"值"两种内容，点一行是选中它，再选择复制路径还是值。所以复制整个格式化结果用工具栏的"复制结果"，它在两种视图里都可用。

**在哪儿粘贴都行。** 在页面空白处按 ⌘V / Ctrl V。当前工具能用这段内容，就留在当前工具：

| 当前工具 | 粘贴的内容 | 结果 |
|---|---|---|
| 生成二维码 | 任意文本 | 填入内容 |
| JSON 对比 | JSON / TOML | 填入最近没有编辑过的一侧：连续粘贴两次，依次填入 A 和 B |
| Base64 | 任意文本 | 填入输入框。Base64 或 data URL 自动切到"解码"，其他文本切到"编码"，切换时有提示 |
| 哈希 | 哈希值（已有文本或文件时） | 填入"核对"，已加载的文件保留 |
| 哈希 | 其他文本 | 作为要计算哈希的文本 |
| 文本对比 | 任意文本 | 和 JSON 对比一样，依次填入 A 和 B |
| URL / Unicode / HTML 编解码、Hex、转义 | 任意文本 | 填入输入框，按内容选择方向（有 `%XX`、`\u4e2d`、`&lt;`、十六进制字节、反斜杠转义时选"解码 / 还原"） |
| Gzip | 任意文本 | Base64 或十六进制写的 gzip / zlib 数据（按文件头判断）切到"解压"，其他切到"压缩" |
| YAML / XML / SQL 格式化、正则（测试文本）、命名转换、字数统计、文本处理 | 任意文本 | 填入输入框 |
| JSON Schema 校验 | JSON | 像 schema 的（有 `$schema`，或顶层有 `type` 和 `properties` / `items`）填入 Schema，其他填入数据 |
| 进制转换 | 整数 | 带 `0x` / `0b` / `0o` 前缀或十进制的填入十进制框，只能按十六进制读的（如 `beef`）填入十六进制框 |
| URL 解析、JWT、UUID、Cron、颜色 | 这个工具能识别的值 | 填入输入框；不是这类值时按下表打开别的工具 |

| 粘贴的内容 | 打开 |

判断 Base64 的依据：data URL，或者能完整解码成可读 UTF-8 文本（或已知文件类型）的 Base64。普通单词不会被误判：10 万个 8–19 位的随机字母数字串里，没有一个被判成 Base64。

**拖入文件。**

| 当前工具 | 拖入 | 结果 |

| Base64、哈希、Hex、Gzip | 任意文件（一次一个） | 按文件原样处理。Base64 在"解码"模式下，内容是 Base64 的文本文件会填入输入框，其他文件改为编码。Gzip 按文件头选择解压或压缩 |
| 文本对比 | 一个或两个文本文件 | 依次填入 A / B，或分别填入 A 和 B |
| JSON 对比 | 一个 .json / .toml | 填入下一侧 |
| JSON 对比 | 两个 .json / .toml | 分别填入 A 和 B |
| 其他工具 | 图片 | 识别二维码 |

| 其他工具 | 其他文本文件（.txt、.csv、.log、.md 等） | 和粘贴同样的规则 |

**用撤销代替确认。** 会替换已有内容的操作（示例、清空、格式转换、粘贴、拖入文件）直接执行，提示里有"撤销"，被替换的文件也能恢复。没有"确定要清空吗？"这类确认框。

**自动判断，但显示出来。** 时间戳的单位、各编解码工具的方向、对比填入哪一侧、Cron 按哪种规则解析，都由内容决定。判断结果写在界面或提示里，改回只要一次点击。

**布局按工具记忆。** 输入和结果默认左右排列。拖动中间的间隔调整两边宽度（双击恢复各占一半）；按住结果顶部的把手，结果窗口整个跟着鼠标走：往下拉约 70 px，布局当场变成上下排列，输入窗口随之伸展，落点显示为虚线占位。拿着的窗口始终和虚线占位一样大（切换时一起变宽或变窄），松手后就是这个大小；它不会移出工具区，放到下方时和工具区一样宽，只上下移动。往上或往右拿约 70 px（往右约 110 px），又变回左右排列。距离从上一次切换的位置算起，所以不会来回跳。拿着的窗口上方有标签写明"松开 · 放在右侧"或"松开 · 放在下方"。松手后窗口滑进位置；放到下方时，如果结果大部分在屏幕下面，页面会滚动让它露出来。默认高度铺满窗口：左右排列时两个框一直延伸到页面底部留白处；上下排列时输入框和结果框平分这段高度，两个框都在屏幕内。窗口大小或字号改变时重新计算。框的高度不随结果内容变化：结果变长、变短（比如切换压缩）都在框内滚动，只有拖横线才改变高度。调整高度：左右排列时拖动下方的横线（两个框一起变），上下排列时拖动两者之间的横线，最低 120 px；拖过之后两种排列共用这个输入框高度，切换排列时不再改变。上下排列时拖动结果下方的横线单独调整结果框高度（最低 160 px）。设了高度后，框里的滚动区域随之伸缩，放不下的内容在框内滚动；双击横线恢复默认。单击把手直接切换。上下排列时输入和结果都占满内容区宽度，内容区本身最宽 1320 px 并保留页边距。每个工具分别记住自己的排列、宽度和各个高度。屏幕较窄（内容区不到 720 px）时始终上下排列。

**字号。** 侧栏底部的"A− 100% A+"调整右侧工具区的字号：文字、间距、卡片一起按比例缩放（100%–160%，只放大不缩小），侧栏保持原样；点百分比恢复 100%。设置保存在本地。

**键盘。**
- ⌘K / Ctrl K 或 `/` 搜索工具，支持中文、英文和拼音首字母，Enter 打开。在搜索框里粘贴内容，第一项就是"用对应工具处理"。
- ⌘B 收起侧栏。
- 时间输入框里按 ↑ ↓ 调整光标所在的那一段。

### 2. 不悄悄改动数据：具体保证

- **格式化**只改变空白和缩进：JSON 的每个记号（数字、字符串转义、重复键）、TOML 的每个值的原始写法和每条注释都原样输出。输出前会重新解析并逐项校验，校验不通过就报错，不输出。
- **JSON ⇄ TOML 转换**遇到目标格式无法精确表示的值（超出 64 位的整数、超出双精度的小数、`null`、`nan` / `inf`、重复键）会拒绝转换并指出位置；日期时间转成 JSON 字符串时会提示。
- **差异对比**按精确的十进制值比较数字；两边都是 TOML 时区分整数和浮点数；值相同但写法不同（如 `1.0` 与 `1`、`0xFF` 与 `255`）单独标为"写法不同"。看起来相近的修改会注明原因：类型变化（如 TOML 的 `1` → `1.0` 是整数 → 浮点数，`"1979-05-27"` → `1979-05-27` 是字符串 → 日期），或"同一时刻，时区偏移不同"。值里的换行和连续空格按原样显示。
- **时间戳**保留毫秒以下的精度（微秒、纳秒）；夏令时切换导致某个本地时间出现两次或不存在时会提示。1900 年前后各地使用的地方平时（如上海 +08:05:43）按秒显示偏移，ISO 文本解析回去是同一时刻。全角数字（中文输入法全角模式）可以识别。
- **二维码识别**自行解码原始字节（UTF-8、GB18030、Shift_JIS），不是 UTF-8 时标明所用编码；无法按 UTF-8 编码的文本不会生成二维码。
- **复制**：内容含 NUL 或孤立代理字符（系统剪贴板可能改动）时会提示，"复制值"改为复制转义写法。
- **Base64 / 哈希**：文本按 UTF-8 编码，含孤立代理字符（没有 UTF-8 形式）时拒绝，不会替换成 U+FFFD。浏览器输入框会把 CRLF 换行转成 LF，粘贴的内容含 CRLF 时会提示，可以选择按 CRLF 计算，或直接拖入文件按原样计算。解码时容忍的写法（空白换行、缺少补齐、URL 安全字符集、data URL 前缀、最后一个字符的多余位）都会列出；无法解码时指出位置。MD5、SHA-1、SHA-256 是自己实现的（浏览器自带的 Web Crypto 没有 MD5，且非 HTTPS 页面不可用），测试中与 Node 的 `crypto` 逐一比对。
- **YAML / XML / SQL 格式化**同样只改空白和缩进，输出前重新解析逐项校验，不通过就不输出：YAML 的数字、布尔值、`null` 按原写法输出（`0x1F`、`1e3`、`0.10000000000000000555` 不会被改写），每条注释保留；XML 只调整元素之间的空白，含正文的元素和 `xml:space="preserve"` 原样保留；SQL 逐个记号比对，字符串、带引号的名称、数字、注释、运算符都不变，只有选择了大小写时关键字才会改大小写，多行注释的缩进随代码调整时会提示。
- **JSON Schema 校验**：重复键直接报错；超出双精度的数字只能近似比较，会列出；schema 里不认识的关键字列出"已忽略"；不支持的 draft-04 和外部 `$ref` 直接说明，不会假装校验通过；`$ref` 绕回自身（如 `{"$ref": "#"}`）时说明会无限循环。
- **编解码与转义**：URL 解码得到的字节不是 UTF-8 时，只在能按 GB18030 解码时才解码并注明；"+"默认保留，需要时再选"+ 表示空格"；HTML 实体缺少结尾 `;` 时原样保留并提示；Shell 还原遇到 `$`、`` ` `` 展开或运算符时拒绝；C 转义避开三字符组（`??`）；无法按 UTF-8 编码的文本拒绝处理。
- **进制转换**用任意精度整数，不会在 2^53 之后出错；小数直接拒绝。
- **JWT**：载荷里的数字按原写法显示（不会把 `12345678901234567890` 变成 `12345678901234567000`）；签名用浏览器的 Web Crypto 校验，密钥只在内存里，不保存。
- **Cron**：按所选时区计算，夏令时跳过的时刻不会列出，并说明有几个；重复出现的时刻标 `*`。Unix cron 的"日"和"星期"同时指定时按"满足其一"；其中一个以 `*` 开头（如 `*/2`）时按"同时满足"——这是 Vixie cron / cronie（多数 Linux 系统）的规则，Node.js 的 cron-parser 等实现在这一点上不同，界面上会说明。Spring / Quartz 按"同时满足"。
- **颜色**：超出 sRGB 的 OKLCH 颜色降低彩度映射，并提示；对比度向下截断到两位小数，4.47 不会显示成 4.5 而误判通过。
- **UUID** 用浏览器的安全随机数生成；生成的值不保存。
- **大模型对话测试**的 API key 只在本机浏览器里使用，请求从浏览器直接发到你填写的接口地址，不经过本网站的服务器；默认不保存，勾选"记住 key"后才存到本机浏览器，取消勾选即删除。对话只保存在当前页面，刷新后清空。请求失败时显示接口返回的 HTTP 状态和原始错误信息；连不上时说明可能的原因（地址、网络或接口不允许浏览器跨域访问），不自动重试。
- **插件**的代码只存在本机浏览器（localStorage），插件自己存的数据也只在本机（IndexedDB，按插件分开，删除插件时一并删除）。插件在没有同源权限的沙箱 iframe 里运行，origin 为 `null`：读不到工具箱页面、它的存储和其他工具的数据（包括大模型工具里记住的 key）；只能通过 `toolbox` 对象请求网络、读写自己的存储、复制和提示。
- **正则**在单独的线程里运行，超过 1.5 秒（灾难性回溯）就停止并说明，页面不会卡死；正则引擎自身放弃（回溯太深）时也会说明原因。
- **大输入不卡死页面**：
  - YAML 的重复键一次扫描查出（5 万行的文件约 5 秒，原来要 4 分多钟）；URL 解码、Hex 转换按块处理（几 MB 在 1 秒内）。
  - 文本对比在 1.5 秒内算不出最少改动的逐行对齐时，开头和结尾相同的行照常对齐，中间整体标为删除再新增（仍然是正确的差异），并注明；行内只在改动不多时标出具体字符。
  - 结果超过 20 万个字符时只显示开头部分并注明，点击仍复制全部。
  - Gzip 解压结果超过 256 MB 时停止并说明；超过 64 MB 的结果不在页面里按文本显示，可下载。
- **嵌套太深、意外错误**：嵌套层级超出浏览器递归上限的 XML / YAML / SQL 会说明原因；YAML 里没有锚点的别名（如把 `*.log` 当成 YAML）报告在出错的位置。万一某个工具遇到意外错误，只在这个工具的位置显示错误，页面其余部分照常可用，并可一键清空这个工具的输入（可撤销）。
- **不会丢输入**：替换已有内容的操作都能撤销（见上文）。
- **显示如实**：不可见字符和文字方向控制字符（如 U+202E）在结果、路径、错误信息和提示中标出（复制时仍是原字符）；语法错误在出错的那一行里直接标出出错的字符；极大的差异结果分段显示并注明总数。
- **本地保存**：输入过大存不下时会提示，并删除旧副本，避免刷新后看到过期内容。超过 4 万字符的输入在停止输入后才处理，处理中不能复制或转换。

## 功能

- **时间戳转换**：秒 / 毫秒 / 微秒 / 纳秒自动识别；时区可搜索切换，默认本机时区，记住上次选择与最近使用；时间输入支持 `2026-10-26 14:30`、`明天 9点`、`下午3点半`、`10/26 9:00`、`now` 等写法，↑↓ 逐段调整，快捷按钮 ±1 时 / ±1 天。
- **生成二维码**：实时生成，支持中文，容错等级 L/M/Q/H；点二维码复制图片，也可下载 PNG。
- **识别二维码**：粘贴、拖入或选择图片，一图多码并在图上标号；点识别出的内容复制，多个码可一次复制全部；图片仅在本地处理。
- **JSON / TOML 格式化**：结构视图可折叠、按层级折叠，选中一行后复制路径或值；缩进（JSON：2 / 4 空格、Tab 或压缩成一行；TOML：2 / 4 空格、Tab 或不缩进，表头按层级缩进、表下的键再缩进一级，多行字符串里的内容不动）、按 key 排序、JSON ⇄ TOML 互转；错误定位到行列。
- **JSON 对比**：语义对比（忽略 key 顺序和空白），可忽略数组顺序、仅显示差异，合并视图 / 差异清单；也支持 TOML 输入。
- **Base64**：文本或任意文件编码（标准 / URL 安全字符集，可选补齐，文件可输出 data URL）；解码 Base64 或 data URL，文本直接显示，二进制以十六进制显示并可下载，图片可预览。
- **哈希**：同时算出 MD5、SHA-1、SHA-256（十六进制大小写或 Base64）；文本按 UTF-8 计算，文件按原样分块计算（大文件不卡页面）；可粘贴期望值核对，支持十六进制、Base64（如 SRI 的 `sha256-…`）和 `sha256sum` 输出的一行。
- **Cron 表达式**：Unix（5 位）、Spring（6 位，含秒）、Quartz（6–7 位）自动识别或手动选择；中文描述；按所选时区列出接下来 10 次执行时间。另有可视化编辑：先选频率（每分钟、每隔几分钟、每小时、每天、每周、每月、每年），再点选星期 / 日期 / 月份、填时间，表达式自动生成；"高级"可逐个字段选择每个 / 指定 / 范围 / 间隔。编辑器和表达式双向同步：改表达式，编辑器也跟着变；编辑器拆不开的写法（如 `L`、`W`、`#`）原样保留，可直接修改。Quartz 自动写入 `?`，星期按周日 = 1 写出。
- **YAML / XML / SQL 格式化**：2 / 4 空格（XML 可用 Tab）；XML 和 SQL 还可以压缩：XML 去掉元素之间的空白（正文、混合内容和 `xml:space="preserve"` 不变），SQL 压成一行（连续空白变成一个空格，`,` `(` `)` `;` 旁边的空白去掉，`--` 注释后保留换行），同样逐项校验。YAML 和 TOML 没有压缩选项：YAML 压成一行要改成流式写法，TOML 的表头必须单独占一行。SQL 支持 20 种方言、关键字大写 / 小写 / 保持。
- **语法着色**：YAML / XML / SQL 的结果、JSON / TOML 的"文本"视图、JWT 的头部和载荷按语法着色（键、字符串、数字、布尔值、关键字、函数、注释、标签和属性）。着色只是给原文分段加颜色，复制和选中的仍是原文；超过 10 万字符的结果不着色，以保持流畅。对比工具不做语法着色，颜色用来表示增删改。
- **JSON Schema 校验**：draft-06、07、2019-09、2020-12，含 `format`；错误带 JSONPath，中文说明。
- **文本对比**：逐行对比并标出行内改动的字符；可忽略空白、大小写，仅显示差异；点结果复制统一格式的差异文本。
- **URL 编解码**：组件 / 整个链接 / 表单三种编码。**Unicode 转义**：`\uXXXX`、`\u{…}`、`&#x…;`、`U+XXXX`，附字符明细（码点、UTF-8、UTF-16）。**HTML 实体**：三种编码范围。**Hex**：文本或文件 ⇄ 十六进制，分隔符和前缀可选。**进制转换**：二、八、十、十六进制和一个自定义进制（2–36）各一个输入框，改哪个其余都同步；点框内全选，点标签复制；8–128 位有符号 / 无符号视图。**Gzip**：gzip / zlib / raw deflate 压缩解压，文本或文件。**转义 / 还原**：JSON、JavaScript、Java、C、SQL、Shell 字符串。
- **URL 解析**：协议、用户、主机、端口、路径（含解码后）、查询参数逐项列出。**JWT 解码**：头部、载荷、过期 / 签发 / 生效时间，可选校验签名（HS / RS / PS / ES / EdDSA）。**颜色转换**：HEX / RGB / HSL / OKLCH、取色器、WCAG 对比度检查。
- **正则表达式测试**（JavaScript 语法）：高亮匹配、列出分组（含命名分组）、替换预览，可直接粘贴 `/…/flags`。**命名转换**：camelCase、snake_case 等 9 种，每行一个。**字数统计**：按显示的字符、词、中日韩字符、行、段落、UTF-8 字节等。**文本处理**：去掉首尾空白、去空行、去重、排序（含自然顺序、按长度）、反转。
- **UUID**：批量生成 v4 / v7，解析任意 UUID 的版本、变体和其中的时间。
- **大模型对话测试**：填入 Anthropic 或 OpenAI 兼容接口的地址、key 和模型名（"列出模型"可从接口获取），多轮对话、流式输出、可随时停止、重新生成；回复按 Markdown 显示（表格、列表、代码块，JSON / YAML / XML / SQL / TOML 代码块着色），有思考过程时可展开查看；每条回复显示首字时间、总耗时、输入 / 输出 token 数、结束原因和实际应答的模型。Anthropic 接口的多轮对话把上一条回复（含思考块）原样传回。key 以 `Authorization: Bearer` 发送；接口地址不是官方地址时，同时带上 `x-api-key`，兼容只读这个头的中转服务。这部分代码和用到的 SDK 只在打开这个工具时才下载。
- **我的插件**：自己写的网页（HTML + JavaScript + CSS），粘贴代码或导入 `.html` 安装后，成为左侧"我的插件"里的一个工具；只保存在当前浏览器里，在隔离环境里运行。用法见下方"我的插件"一节。
- **时间戳**另外识别 ULID；15–19 位数字同时按 X / Twitter、Discord 的 Snowflake ID 显示时间。
- **全局**：中英切换；浅色 / 深色 / 跟随系统；输入与偏好（各工具的选项）保存在本地。

所有依赖（字体、二维码、TOML / YAML 解析、SQL 格式化、JSON Schema 校验、文本差异）都打包在本地，不按需加载，可离线使用。

## 我的插件

插件就是一个网页：任意 HTML、CSS、JavaScript，也可以用 `<script src="https://…">` 引入任何库。在左侧"我的插件 → 添加插件"里粘贴代码（或导入 `.html` 文件、从空白模板开始，空白模板说明了全部接口），点"安装"后它成为左侧的一个工具：名字取自网页的 `<title>`，图标用 `<meta name="toolbox-icon" content="¥">` 指定（不写时取名字的前一两个字）。打开插件后，顶部有"编辑代码""导出 .html""删除"（删除要点两次）。工具箱页面打开期间，所有插件都在后台运行（无论当前在哪个工具），打开的那个高度铺满窗口；命令面板也能搜到插件。

插件在隔离的环境里运行，通过 `window.toolbox` 与工具箱交互：

| 接口 | 作用 |
|---|---|
| `await toolbox.fetch(url, { method, headers, body })` | 由工具箱代发请求，返回 `{ ok, status, headers, text, json() }`；连不上时抛出 `connect: …`，30 秒无响应抛出 `timeout: …` |
| `await toolbox.storage.get(key)` / `set(key, value)` / `remove(key)` | 这个插件自己的存储（值可以是任意可结构化克隆的数据），保存在本机浏览器 |
| `toolbox.copy(text)`、`toolbox.toast(text)` | 复制到剪贴板、显示提示 |

工具箱的配色以 CSS 变量传入（`--ink`、`--mut`、`--faint`、`--bg`、`--card`、`--sub`、`--line`、`--acc`、`--add`、`--del`、`--chg` 等，切换主题时同步更新，并触发 `toolbox-theme` 事件），`.card`、`.btn`、`.btn.primary`、`input`、`textarea`、`label` 有基础样式。工具箱自带 uPlot 图表库，写 `<script src="toolbox:uplot"></script>` 和 `<link rel="stylesheet" href="toolbox:uplot.css">` 即可使用，不需要联网。

工具箱不内置具体的插件；额度看板这类只给自己用的插件，代码由使用者自己保存和粘贴。

**接口不允许浏览器直接访问时**（没有 CORS 头、不处理 OPTIONS 预检）：在自己电脑上运行转发程序 `scripts/local-proxy.py`（只用 Python 标准库，3.8+）：

```bash
python3 scripts/local-proxy.py http://你的接口地址            # 默认端口 8787
python3 scripts/local-proxy.py http://你的接口地址 --port 8787 --origin http://public-pages.ryuryu.fun:8081
```

然后把插件里的地址换成 `http://127.0.0.1:8787/...`（路径和查询参数不变）。转发程序只监听 127.0.0.1，只接受 `--origin` 指定的工具箱地址发来的请求（默认 `http://public-pages.ryuryu.fun:8081`，可重复指定；插件的请求由工具箱代发，所以来源就是工具箱的地址），原样转发路径、查询参数、`Authorization` 和请求体，加上浏览器需要的 CORS 头；不保存任何内容，日志里只有方法、路径和状态码，没有 key。连不上目标接口时返回 502 和原因。Chrome 第一次从网页访问本机地址时会询问是否允许访问本地网络，允许一次即可。

### 新增工具

1. 在 `src/i18n.ts` 的 `TOOLS` 中添加一项（`id`、分类、图标、中英文名称、搜索关键词）；新分类同时加到 `CATS` 和 `CAT_ORDER`。
2. 在 `src/tools/` 下实现组件，通过 `useApp()` 读取状态和文案。单个结果值用 `Kv`，大段结果文本用 `CopyBlock`（都在 `components/Kv.tsx`），点击即复制，不要再另放复制按钮。文本类工具可直接用 `components/Panes.tsx` 的 `TextIn`、`OutCard`、`TextOut`、`ErrLine`；工具选项用 `useOpt('工具.选项', 默认值)`，会随偏好保存。要保存的输入加到 `store.tsx` 的 `INPUT_KEYS`。有一个输入和一个结果的工具，用 `components/Split.tsx` 的 `<Pair>{输入}{结果}</Pair>` 排列，就能拖动和记忆布局。
3. 在 `src/App.tsx` 中按 `S.tool` 渲染该组件。如果这个工具能直接使用粘贴的文本或拖入的文件，在 `takeText` / `handleFiles` 里加上它的规则，并更新上面的表格。
4. 对照"产品原则"检查：最常见的任务要几步，能不能少一步；有没有悄悄改动数据的地方。在 `e2e/` 中为新约定加测试。
