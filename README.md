# 工具箱 · Toolbox

面向开发者的跨端（PC + 移动端）工具箱，按 Claude Design 交付的高保真原型（`design/project/Toolbox.dc.html`，1a 经典侧栏方向）实现。

## 功能

- **时间戳转换**：秒 / 毫秒 / 微秒 / 纳秒自动识别；时区可搜索切换，默认本机时区，记住上次选择与最近使用；时间输入支持 `2026-10-26 14:30`、`明天 9点`、`下午3点半`、`10/26 9:00`、`now` 等写法，↑↓ 逐段调整，快捷按钮 ±1 时 / ±1 天。
- **生成二维码**：实时生成，支持中文，容错等级 L/M/Q/H，下载 PNG、复制图片。
- **识别二维码**：粘贴、拖入或选择图片，一图多码并在图上标号；图片仅在本地处理。
- **JSON / TOML 格式化**：结构视图可折叠、按层级折叠，点击行复制路径或值；缩进、按 key 排序、压缩复制、JSON ⇄ TOML 互转；错误定位到行列。
- **JSON 对比**：语义对比（忽略 key 顺序和空白），可忽略数组顺序、仅显示差异，合并视图 / 差异清单；也支持 TOML 输入。
- **全局**：⌘K / Ctrl K 或 `/` 搜索工具（中文、英文、拼音首字母）；⌘B 收起侧栏；在空白处粘贴内容自动打开对应工具；拖入图片或 .json / .toml 文件；中英切换；浅色 / 深色 / 跟随系统；输入与偏好保存在本地。

所有依赖（字体、二维码、TOML 解析）都打包在本地，可离线使用。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 构建到 dist/
npm test         # 全部测试
```

### 数据不变的保证

- **格式化**只改变空白和缩进：JSON 的每个记号（数字、字符串转义、重复键）、TOML 的每个值的原始写法和每条注释都原样输出。输出前会重新解析并逐项校验，校验不通过就报错，不输出。
- **JSON ⇄ TOML 转换**遇到目标格式无法精确表示的值（超出 64 位的整数、超出双精度的小数、`null`、`nan` / `inf`、重复键）会拒绝转换并指出位置；日期时间转成 JSON 字符串时会提示。
- **差异对比**按精确的十进制值比较数字；两边都是 TOML 时区分整数和浮点数；值相同但写法不同（如 `1.0` 与 `1`、`0xFF` 与 `255`）单独标为"写法不同"。
- **时间戳**保留毫秒以下的精度（微秒、纳秒）；夏令时切换导致某个本地时间出现两次或不存在时会提示。
- **二维码识别**自行解码原始字节（UTF-8、GB18030、Shift_JIS），不是 UTF-8 时标明所用编码；无法按 UTF-8 编码的文本不会生成二维码。
- **复制**：内容含 NUL 或孤立代理字符（系统剪贴板可能改动）时会提示，"复制值"改为复制转义写法。
- **不会丢输入**：示例、清空、格式转换、智能粘贴、拖入文件会替换已有内容时，提示里提供"撤销"。
- **显示如实**：不可见字符和文字方向控制字符（如 U+202E）在结果中标出（复制时仍是原字符）；极大的差异结果分段显示并注明总数。
- **本地保存**：输入过大存不下时会提示，并删除旧副本，避免刷新后看到过期内容。超过 200 KB 的输入在停止输入后才处理，处理中不能复制或转换。

测试包括（另用植入错误测试检验过测试本身：31 个故意植入的错误全部被发现）：单元测试（`src/lib/data.test.ts`）、TOML 官方一致性测试集（`test/toml-test`，来自 [toml-lang/toml-test](https://github.com/toml-lang/toml-test)，MIT 许可）、以及随机化测试（`src/lib/fuzz.test.ts`：解析器与 `JSON.parse` 判断一致、格式化无损且稳定、篡改必被校验发现、差异结果可还原两侧）。

构建产物是纯静态文件（`base: './'`），可部署到任意静态托管。

## 目录

```
src/
  App.tsx              应用外壳：全局快捷键、智能粘贴、拖放、持久化
  store.tsx            状态定义、localStorage 读写、Context
  i18n.ts              工具注册表、分类与中英文文案（新增工具从这里开始）
  components/          侧栏 / 移动端顶栏、命令面板、分段控件
  tools/               各工具页面
  lib/                 时间解析、数据对比、二维码等纯函数
design/                Claude Design 交付的原型与对话记录
```

### 新增工具

1. 在 `src/i18n.ts` 的 `TOOLS` 中添加一项（`id`、分类、图标、中英文名称、搜索关键词）；新分类同时加到 `CATS` 和 `CAT_ORDER`。
2. 在 `src/tools/` 下实现组件，通过 `useApp()` 读取状态和文案。
3. 在 `src/App.tsx` 中按 `S.tool` 渲染该组件。
