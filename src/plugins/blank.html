这是一个完整的网页：写任何 HTML、CSS、JavaScript，也可以用 <script src="https://…"> 引入库。 它在隔离的环境里运行，读不到工具箱的数据；需要时通过 toolbox：

  • await toolbox.fetch(url, { method, headers, body }) → { ok, status, headers, text, json() }，由工具箱代发（连不上时抛出 connect: …）
  • await toolbox.storage.get(key) / set(key, value) / remove(key)：这个插件自己的存储，保存在本机浏览器
  • toolbox.copy(text)、toolbox.toast(text)
