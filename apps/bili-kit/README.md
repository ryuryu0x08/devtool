# bili-kit

B站内部工具包，一个 Chrome 插件装齐给知了文档加的两件事：

| 功能 | 作用范围 | 说明 |
| --- | --- | --- |
| 夜间模式 | `aistudio.bilibili.co` 全部页面 | 夜间 / 深夜 / 跟随系统 / 关闭；可设时间段自动开启；单个网页可固定日间 / 夜间 / 深夜 |
| Mermaid 折叠 | `aistudio.bilibili.co` 全部页面里的文档 | 树形图（如域功能图）默认只显示第一层，节点旁数字可展开，图左上角有「收起 / 展开」 |

两个功能互相独立：关掉夜间不影响折叠，反之亦然。

## 安装

1. 打开 `chrome://extensions`，打开右上角「开发者模式」。
2. 点「加载已解压的扩展程序」，选这个目录（`apps/bili-kit`）。
3. 打开或刷新知了页面。
4. 从 `chrome://extensions` 里移除旧的 `mermaid-fold` 和 `zhiliao-dark-mode`：它们和本插件功能重叠，同时启用会看到两份「收起 / 展开」按钮、夜间样式叠两遍。

## 夜间模式

点工具栏图标选择：

| 模式 | 效果 |
| --- | --- |
| 跟随系统（默认） | 系统深色时用夜间，浅色时不变 |
| 夜间 | 深灰底、浅灰字 |
| 深夜 | 更暗，略偏暖色，减少蓝光 |
| 关闭 | 原样显示 |

**自动开启**：勾选「时间段自动开夜间」，设开始和结束时间（`20:00` 至 `08:00`，跨午夜也行）。时间段内「跟随系统」按夜间算；明确选了夜间、深夜或关闭的以你选的为准。时间段外不做干预。开始与结束相同等于不生效。

快捷键 `Alt+Shift+D` 翻转当前页面看到的：现在是暗色就切到日间，否则切到夜间。网页固定了主题就改它的固定主题，否则改全局模式。可在 `chrome://extensions/shortcuts` 改键。

**固定此网页**：在知了页面点工具栏图标，「此网页」里选日间、夜间或深夜，这个网页从此一律用它，不管上面的全局模式、系统深浅色和时间段；选「跟随全局」取消。网页按网址区分，不看 `?` 和 `#` 后面的部分，所以同一篇文档带不带锚点都算一个。站内切换文档不刷新页面，网址一变就按新网页重新判断。

**管理固定的网页**：弹窗里「管理固定主题的网页」（括号里是已固定的个数，没有时写「还没有」），或 `chrome://extensions` 里本插件的「扩展程序选项」，打开列表页：显示标题和完整网址，最近设置的在前，可改主题、删除单个或全部删除。管理页已经开着时再点会切过去，不会再开一个。

页面打开时扩展存储要异步读，所以把模式、时间段和各网页的主题另存一份在知了的 `localStorage`（`bk-dark-settings`），第一帧就按它上色，避免固定了日间的网页先闪一下暗色。

实现：知了同时用了 CSS 变量、antd、Tailwind 和大量行内颜色，只改设计变量会漏掉大部分元素。所以对 `<html>` 整体做 `invert + hue-rotate`（保留原色相），再把图片、视频、canvas、iframe 反色回来；Mermaid 图也反色回来，保持图里原有的配色。已知限制：透明底、黑色线条的 PNG 在暗色背景上会看不清。

## Mermaid 折叠

树形图（只有一个根、每个节点只有一个上级、连线不带文字）打开时只显示第一层。节点旁的数字是被收起的节点数，点开；展开后变 `−`，点它收起。图左上角「收起」回到只显示第一层，「展开」显示全部。快捷键 `Alt+Shift+M` 折叠或展开鼠标所在的那张图。

流程图（连线带「是 / 否」、分支汇合）保持原样。

实现要点：

- 不重新调用 Mermaid：直接复用页面已经画好的 SVG，按思维导图的方式重算位置（`src/layout.js`），只改节点位置、隐藏收起部分、重画连线、改 `viewBox`。每次约 10 ms。
- 页面打开时本来会一次画完文档里所有图（38 张图会让浏览器停约 4.5 秒）。插件在页面加载 Mermaid 之前接管它（`src/early.js`、`src/defer.js`）：图离屏幕不到一屏才画，一张接一张，每张之间让出主线程，未画的图显示页面自带的转圈。
- 不改文档：`<mermaid-viewer>` 的 `code` 和正文都不动，双击编辑看到的还是原文。

这两种脚本都要读页面里的 JS 属性，所以以 `world: "MAIN"` 运行。

## 文件

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 权限、三组页面脚本（都在知了的全部页面上）、选项页、两个快捷键 |
| `popup.html`、`popup.js` | 设置弹窗：此网页固定的主题、夜间模式、自动开启时间段 |
| `manage.html`、`manage.js` | 固定主题的网页列表：改主题、删除（也是扩展的选项页） |
| `background.js` | 快捷键：开关夜间（交给页面脚本按当前页面判断）、折叠悬停的图 |
| `src/night.js` | 夜间模式规则：模式换算、时间段判断、网页的键和固定主题；不碰 DOM |
| `src/night-page.js` | 页面里设 `data-bk-dark`，读扩展存储、写页面缓存，网址变了重新判断 |
| `src/dark.css` | 夜间 / 深夜的滤镜 |
| `src/defer.js` | 让 Mermaid 的 `parse` / `render` 等到图接近屏幕再一张张执行 |
| `src/early.js` | 页面加载 Mermaid 前接管它 |
| `src/fold.js` | 把 Mermaid 文本解析成树 |
| `src/layout.js` | 树的排版和连线 |
| `src/mermaid.js` | 页面里：画折叠按钮、按排版移动节点 |

## 测试

```bash
node --test apps/bili-kit/test/*.test.cjs
```

`test/night.test.cjs` 测模式换算、跨午夜的时间段、网页的键、固定主题的优先级和快捷键的翻转；`test/fold.test.cjs`、`test/layout.test.cjs`、`test/defer.test.cjs` 测树的解析、排版和延迟渲染。
